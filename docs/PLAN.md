# 幼年班管理系統完整方案

## 目標與維護方式

家長用手機查看課表、準備物品、近期活動、相簿與孩子的進步；教員用同一網站進入後台完成點名、加分及發布內容。班負責管理學期、帳號與 Google 資料。日常使用不需要修改程式。

網站放 GitHub Pages；個人資料與照片保留在教會所管理的 Google 帳號。第一版以一個幼年班為主，預設班級代碼 children，教員權限保留班級範圍。多班分別命名／管理、跨班報表尚未提供完整管理介面。

## 功能與驗收

| 項目 | 實作方式 | 使用時的結果 |
| --- | --- | --- |
| 登入 | Firebase Google 登入、後端帳號白名單與 UID 綁定 | 未開通帳號無法讀取班級資料 |
| 家長與孩子 | 管理員設定一對多家長關聯 | 一個家長可切換自己的多位孩子 |
| 課表 | 獨立 Google Sheet 的中文「課表」或 Courses 分頁 | 教員編輯並儲存後，家長按重新整理取得更新 |
| 課堂紀錄 | 點名、金句完成、自動加分 | 更正狀態只增減差額，保留積分歷史 |
| 手動積分 | 有原因、有教員、有時間的流水帳 | 可批次加減分；誤登使用撤銷 |
| 相簿 | 草稿、壓縮上傳 Drive、人工確認分享同意、發布 | 家長只能讀取自己班級已發布相簿 |
| 活動與公告 | 後台新增修改、草稿與發布 | 可加入 Google Forms 報名或 Drive 教材 HTTPS 連結 |
| 學員資料 | 後台維護，或從指定 Google Sheet 預覽匯入 | 依固定 id 新增／更新，保留其他學員 |
| 學期 | 新增、設定目前學期、封存舊學期 | 舊資料保留，可查閱；封存後停止登記 |
| 備份 | 每日 JSON 備份到 Drive，30 天保留 | 還原建立新資料表，原表仍保留 |
| 部署 | GitHub Actions 建置、測試、Pages 發布 | 修改網站程式後自動更新，Google 後端另更新部署版本 |

## 建議的初始積分

出席 5 分、遲到 3 分、請假／缺席 0 分、完成金句 3 分。後台可調整 0–100。手動單次 -100 到 100 分且不得為 0。家長查看個人成長，沒有全班排名。

既有狀態未變時保留原分數；若教員日後修改狀態，依修改時的規則計算差額。學期結束後先檢查紀錄，再封存。

## 資料流與權限

~~~mermaid
flowchart TD
  W["GitHub Pages 網站"] --> A["Firebase Google 登入"]
  A --> T["登入憑證"]
  T --> B["Apps Script：驗證與權限"]
  W --> B
  B --> S["Sheets：名單、課表、紀錄"]
  B --> D["Drive：相簿與備份"]
~~~

學員姓名、分數、家長 Email 與照片都不存進公開 GitHub。登入驗證後，由 Apps Script 決定回傳範圍；前台的選單隱藏只負責操作便利，不是權限邊界。

## 班級工作流程

1. 學期前：建立學期、學員、家長與教員帳號，填好課表。
2. 上課前：教員查看材料、複製提醒文字，需要時貼至班級群組。
3. 上課時：點名、登記金句；系統同步積分。
4. 下課後：結束登記、整理精選照片、檢查同意後發布。
5. 學期末：匯出積分、檢查備份、切換新學期並封存舊學期。

## 容量、成本與交接

本設計適合小型班級、精選課堂照片與低量同時操作。Google Apps Script、Sheets、Drive、Firebase Auth 都有方案與使用配額，不能保證任何使用量都免費。這版不需要付費資料庫或 Firebase Storage；實際支出依 Google 帳號容量、使用量及現行方案決定。

照片長邊最多 1600 px，上傳儲存 JPEG 版本，每批最多 10 張；單頁 12 張，照片讀取同時最多 2 個請求。照片檔與試算表寫入不能跨服務原子提交；失敗時可能留下未登記的 Drive 檔案，保留人工核對。文字資料備份不包含照片位元組；攝影原始檔請另行保存。

管理 Google 帳號宜由教會可交接的身分持有。移交時同時交接 GitHub 儲存庫、Apps Script、Firebase 專案、試算表、Drive 資料夾及每日觸發器。

## 可延伸功能（尚未實作）

- Google Calendar：把課程加入個人日曆，或同步教會共用日曆。
- LINE Messaging API：按課表定時發送提醒；需另接官方帳號與確認訊息費用。
- 家長請假表：以 Google Forms 接收，再由教員審核更新點名。
- QR code／感應卡點名：接到既有出席規則，保留人工修正。
- 獎勵兌換：獨立兌換紀錄與審核，不直接覆寫累積分數。
- 多班介面、教員輪值、年度移班及跨班查詢。

這些項目留作後續版本，不會在第一版用無作用按鈕表示已完成。
